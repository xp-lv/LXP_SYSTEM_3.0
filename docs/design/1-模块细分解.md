## 1 · 岛屿模块

| 最小模块 | 功能 |
|---|---|
| 岛体建造 | 生成一座承载**所有树**的浮空岛：地形、悬崖、地表植被；树在岛上有落脚之处，岛随树数生长 |
| 世界管理 | 树的种植与移除、激活与回退；领域作为数据分组管理（增删改名），不在世界中呈现 |

## 2 · 树模块

| 最小模块 | 功能 |
|---|---|
| 树形生成 | 由任务分解结构长出树的骨架：分叉=分解层级，粗细长短=任务体量 |
| 木质外观 | 骨架的树皮质感与受光表现 |
| 状态表达 | 树上三态：断梢红光=待排期、日梢指线=已排期、完成叶团=分叉全部完成（含生长动画） |
| 状态映射 | 任务数据与树形态语言之间的翻译 |
| 呈现编排 | 激活树的细节呈现与其余树的远景呈现 |

## 3 · 顶层目标分解模块（宏观）

| 最小模块 | 功能 |
|---|---|
| 目标画布 | 顶层目标的分解编辑：主目标→二级→三级 |
| 月度分配 | 把顶层任务分配到月份；移出、换月 |
| 月度详情 | 某个月内做月度分解、看周排期 |
| 周度球 | 月份的周导航与排周入口 |
| 树切换器 | 切换当前编辑哪棵树 |

## 4 · 周度目标分解模块（微观）

| 最小模块 | 功能 |
|---|---|
| 周画布 | 周任务的分解编辑与工时填写 |
| 周度条 | 跨月的周导航：选周、回宏观 |
| 七日泡泡 | 任务落日到具体哪天；当日容量与负载 |
| 临时任务 | 日程式任务的增删与落日 |
| 历史周只读 | 过去周的只读回看 |

## 5 · 今日模块

| 最小模块 | 功能 |
|---|---|
| 周计划树 | 本周已落日任务成一棵树，独占整个场景 |
| 事项清单 | 当日任务的勾选完成、排序、临时新增、辅助分解 |
| 补点系统 | 超时任务的补做安排：落果/落叶堆的呈现与补点选择 |
| 日视角切换 | 按天查看的导航（周↔日） |
| 进度读数 | 今日负载与完成度 |

## 6 · 星球模块

| 最小模块 | 功能 |
|---|---|
| 星系生成 | 一棵子树化作星系：中心球=选中的树或节点，行星=子级，卫星=孙级 |
| 星球导航 | 进入（右键树/点大纲条目）；点击行星=下钻，点击中心球=返回上级，右键=退回世界 |
| 星球标注 | 每颗球的名称标签与互斥排布 |
| 展开动画 | 进入/退出时星系的生长与收拢 |

## 7 · 数据模块

| 最小模块 | 功能 |
|---|---|
| 节点派生 | 任务树自底向上的汇总计算：工时、进度、断梢、告警 |
| 周期日历 | 月/周/日的周期定义与解析 |
| 变更服务 | 所有数据修改的统一通道 |
| 撤销重做 | 任何修改可撤销/重做 |
| 持久化 | 存档、恢复、备份 |

## 8 · 交互模块

| 最小模块 | 功能 |
|---|---|
| 相机控制 | 视角漫游：旋转、平移、缩放、聚焦 |
| 输入处理 | 指针与键盘输入的接听 |
| 拾取路由 | 点击到的东西该触发什么（单击树=激活、右键树=星球…） |
| 转场动画 | 页面切换时的视觉连续性 |

## 9 · 信息模块

| 最小模块 | 功能 |
|---|---|
| 树选择框 | 当前领域有哪些树、切到哪棵 |
| 任务大纲 | 激活树的层级细节一览；点击条目进入该节点的星球视图 |
| 顶栏读数 | 总进度、断梢、完成、过期 |
| 悬停详情卡 | 指到哪显示那个任务的档案 |
| 小地图 | 岛上树与断梢的俯瞰 |
| 提示层 | 完成反馈、路径面包屑、图例 |

## 10 · 环境模块

| 最小模块 | 功能 |
|---|---|
| 场景底座 | 3D 画面的基础设施 |
| 时段预设 | 昼/黄昏/夜三态氛围 |
| 天空 | 天穹、太阳、云、星空 |
| 氛围粒子 | 光尘与萤火 |
| 风 | 树与草的摇曳 |
| 阴影 | 光影落地 |

## 11 · AI 规划模块

> 把“靠直觉分解任务”升级为“对话澄清 → 系统化分解 → 文档链 → 用户确认 →
> 经变更服务落库”的规划闭环。AI 只提方案，不直接写任务数据。

| 最小模块 | 功能 |
|---|---|
| 对话与需求澄清 | 多轮对话把模糊目标变成结构化需求契约（成功标准/期限/投入/约束/非目标/假设） |
| 系统化分解 | 结果导向 WBS、MECE、依赖与关键路径、0.5–8h 粒度、工时与容量校验，而非直觉拍脑袋 |
| 文档链生成 | 按固定顺序生成目标契约→现状约束→分解结构→任务清单→排期执行→决策记录，并组织到受管文件夹 |
| 方案评审与确认 | 预览分解树、变更摘要、规则与容量告警；用户通过/修改/放弃；未确认禁止落库 |
| 任务落库与分配 | 把确认方案翻译为建树/建任务/改工时/落月周日落成/完成，事务化执行、一步 undo、失败回滚 |
| 上下文构建 | 只读任务树/日历/容量/文档，按需工具读取，控制上下文预算并检测过期 |
| 模型接入与安全 | 服务端 LLM 代理、工具调用/JSON 降级、流式、限流、密钥与 Markdown/XSS 防护 |
