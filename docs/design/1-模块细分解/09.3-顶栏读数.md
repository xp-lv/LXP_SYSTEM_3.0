# 09.3 · 顶栏读数 · 全定义

> 父模块：[信息](./09-信息模块.md) · 状态：〔已定义·demo 验证〕

**是什么**：激活树的全局读数（世界视图顶栏）。

**行为**
- 进度徽章五档：荒芜(0%)→破土(>0)→半坡(>25)→丰收(>50)→圆满(100)，色随档；
- 大字总%；
- 计数行：**断梢**（bare 计数）· **完成** · **过期**（redCount）· **任务数**（leafCount，**不含临时任务**——R26 临时=日程≠规划；日程的度量在今日页进度环。〔已定〕）；
- 异常为 0 时保持中性色（仅真实异常着色——防彩灯效应）；
- 随变更即时刷新。

**输入 → 输出**
- 读：激活树派生；纯读。

**承接**：R16（过期口径）· T6 · 验收 C9（读数与派生一致〔自〕）。

**边界**：不做今日读数（05.5 进度读数）；不做交互。
**待定**：是否加"欠约束工时"（buckets.floating）。
