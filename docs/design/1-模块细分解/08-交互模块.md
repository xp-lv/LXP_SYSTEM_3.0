# 08 · 交互模块 · 完全定义

> 《0-模块分解》模块 8。输入的接听与路由：相机、拾取、键盘、转场。

## 定义与边界

- **定义**：把"用户点了什么/按了什么"翻译成系统动作；相机漫游；页面转场的视觉连续。
- **边界**：**不写任何数据**——只把意图路由给对应模块（写永远走数据通道）；
  不做业务判断。

## 最小功能模块

### 相机控制
- 轨道漫游：旋转/平移/缩放；聚焦（单击树/双击）；回正；
- 机位：激活聚焦、今日固定机位、星球展开取景；缓动曲线统一。

### 输入处理
- 指针：左键拖=旋转、右键/Shift 拖=平移、滚轮=缩放、单击/双击/右键、悬停；
- 键盘：Esc 逐层退出、Cmd/Ctrl+Z 撤销（转交数据模块）。

### 拾取路由
点击到的东西该触发什么（世界视图全表）：

| 点到 | 动作 |
|---|---|
| 树 | 激活该树（转世界管理） |
| 树（右键） | 进入星球（转星球模块） |
| 星系内的球 | 下钻/返回（转星球模块） |
| 落果/落叶堆 | 补点选择器（转今日模块） |
| 岛面 | 无动作（世界只读） |

### 转场动画
- 月↔周（周度球飞移）、周↔日（日泡泡飞移）的共享元素过渡；
  只做视觉连续，不做状态切换（状态由视图路由改）。
