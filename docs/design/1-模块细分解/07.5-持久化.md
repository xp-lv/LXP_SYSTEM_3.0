# 07.5 · 持久化 · 全定义

> 父模块：[数据](./07-数据模块.md) · 状态：〔已定义〕

**是什么**：存档的读写、备份与自愈（schema v2 的执行者）。

**行为**
- 变更链末尾**整包序列化**写入 localStorage（键 `lxp_redesign`）；
- 序列化剔除派生字段（G5，逐字节可 diff）；
- **写入原子性**：序列化成功才写；失败保留旧档+提示导出；
- 载入：版本判断（高版本拒载/低版本走迁移链 v1→v2，任一步失败按损坏处理）；
- 损坏自愈：旧档改名备份（`.bak`）→全新初始态→提示；
- localStorage 不可用/满：内存模式+每次变更提示导出；
- 导出=存档根本身（含 schema 号）；导入校验失败整体拒绝（H2）；
- id 载入后回播最大值续发（《6》id 规则）。

**输入 → 输出**
- 读/写：localStorage；提供：存档事件。

**承接**：《6》§A–F 全部 · A6 · 验收 G3/G5 + C7 错误路径。

**验收**
- 刷新一致〔自〕；三条错误路径（损坏/版本/写满）按 F 表行为〔自〕。

**边界**：不做多端同步；不做自动云备份。
**待定**：H1 旧 app v1 档导入（挂"旧 app 处置"拍板）。
