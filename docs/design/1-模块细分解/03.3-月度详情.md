# 03.3 · 月度详情 · 全定义

> 父模块：[顶层目标分解](./03-顶层目标分解模块.md) · 状态：〔已定义〕

**是什么**：某个月的月度域编辑器（月度分解发生地）。

**行为**
- 结构：「某月」根→落月顶层任务（分组）→其月度分解叶子；同构画布、自由平移、视角保持；
- 悬停顶层任务＋=月度分解（产生 `lvl=month`）；
- 月度任务显示周标签（待排周/第 N 周）；
- 「某月」根＋=本月新建顶层任务（直接落月）；
- **不显示工时**（工时自周度域开始）。

**输入 → 输出**
- 读：该月 assignM 任务；写：month 级结构与 assignM。

**承接**：M7/M10 · R4（lvl 语义）· T17。

**验收**
- 月度计数只算 month 叶子；标题无工时〔自/手〕。

**边界**：不做周排期编辑（落周在周度球）；无临时任务。
**待定**：无。
