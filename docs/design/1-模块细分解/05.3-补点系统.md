# 05.3 · 补点系统 · 全定义

> 父模块：[今日](./05-今日模块.md) · 状态：〔已定义〕

**是什么**：超时任务的补做安排——逾期事实保留，新排期走 makeup。

**行为**
- **落果**：排期/补点在本周且早于今天且未完成的任务，散落树下（点击开补点选择器）；
- **落叶堆**：assignD 早于本周一且未完成且无有效补点（历史欠账，点击回看）；
- **补点选择器**：未来 14 天网格；满日（超容量）灰显不推荐、今日高亮；
  可覆盖更新、可清除（R18）；
- 语义（R17/R20）：逾期重排**不改原 assignD/assignW**（冻结为历史锚点），
  新排期写 `makeup`；未超时任务重排=直接替换；
- 兑现：补点完成→按补点日落果、落果清除（R19）。

**输入 → 输出**
- 读：assignD/makeup/progress/容量；写：makeup（经变更服务）。

**承接**：T5 · R16–R21 · T21（逾期化时机）· 周泡泡 K6（同一 makeup 的另一写入口）。

**验收**
- 落果/落叶堆判定与 R21 一致〔自〕；补点可覆盖/清除〔自〕；
  兑现后落果消失〔手〕。

**边界**：不改原排期（冻结是红线）；满日灰显不阻止。
**待定**：措辞随"时间维度/周树果态"拍板（灵魂/果态词汇）。
