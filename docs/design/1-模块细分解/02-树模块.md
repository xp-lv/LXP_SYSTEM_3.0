# 02 · 树模块 · 完全定义

> 《0-模块分解》模块 2。一棵树 = 一套任务分解结构的**确定性函数**；树上三态是全系统共用的视觉语言。

## 定义与边界

- **定义**：任务树 → 骨架树形 → 三态呈现（红光/指线/叶团）→ 完成动画。
- **边界**：不读日历、不做业务判定（一切经状态映射读派生数据）；不管岛和激活；
  **完成永不改变骨架**——结构与状态分离。

## 最小功能模块

### 树形生成
- 分叉数=分解级数；枝粗=工时份额；**同数据永远同树形**（确定性）。
- 任务类型 A→B→C→D（目标/月/周/日，组织层上限 6 级）；**一般树、每节点可多子**、
  跨层直拆（B1 无 B2 可直拆 C1；有 B2 时 B1 必为内节点、绝不断枝）、封层不回插；
  每叉一根延长枝+侧枝扇形（黄金角错开）；叶子在 D 层=完整末梢、停在 B/C 层=**断枝**
  （断口深度=分解进度，续分解后愈合）。
- 不变量（设计定死，参数以 demo 实现为准）：
  子径只由母端推导、永不逆粗；末梢有可见性地板不消失；
  **长度预算恒定**——分解深浅不改树冠轮廓；整枝平滑弧线+梢端抬头。

### 木质外观
- 树皮质感与受光表现；风摆（层级权重）；投影。

### 状态表达（三态）
- **断梢红光**=未排期且未完成的末梢（呼吸脉冲；夜晚成灯）；
- **日梢指线**=已排期的末梢短果枝；
- **完成叶团**=该分叉下全部完成（含目标级；大小∝工时；easeOutBack 生长动画）；
- 秃干+顶红光=完全未分解的目标。

### 状态映射
- 任务数据 ⇄ 形态语言的翻译：`bare→红光`、`有排期→指线`、`分叉全完成→叶团`；
- 节点位置回写（拾取/相机/星球的锚点来源）。

### 呈现编排
- 激活树：逐枝独立呈现（整树可拾取）；
- 其余树：远景简版（点树=激活）。

## 自动行为（承接《3》§2）

- **A1** 完成分叉 → 即时长叶团+反馈，父级级联判定；
- **A2** 获得排期 → 该末梢红光熄灭换成指线。

## 时序（承接《4》）

- **T3 树生命周期**、**T7 完成级联**（时机待设计）；

## 数据（承接《6》）

只读派生：`bare`、`progress`、排期字段、工时（叶团大小）；经适配层输入，不直连业务。

## 验收（承接《7》C2）

- 子枝基径≤母枝挂点处半径（全树 0 违例）〔自〕；
- 光杆与拆满极限态，根→梢路径差≤8%；中间暂停态冠幅小于满态（断枝短桩=滚动波前缘）〔自〕；
- 停在 B/C 的枝必有可见断口；补分解后断枝长成完整末梢〔手〕；
- 排期→红光消失换指线；取消排期→红光回来〔手〕；
- 完成分叉→叶团长出+反馈；取消→收回；骨架全程不变〔手/视〕；
- 夜晚红光可读、叶团微光〔视〕。
