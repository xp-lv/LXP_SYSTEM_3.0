# 03.5 · 树切换器 · 全定义

> 父模块：[顶层目标分解](./03-顶层目标分解模块.md) · 状态：〔已定义〕

**是什么**：宏观页头部的「领域·树」切换与种植入口（不必回世界点树）。
- **领域管理入口也在此**（01.2）：下拉底部 新增领域 / 改名当前领域 / 删除空领域。

**行为**
- 面包屑+下拉：显示当前领域与树，切换领域/树（=激活切换，世界跟随）；满员时种植钮禁用+原因；
- 「×」删树：二次确认；有未完成规划加强确认（R31）；
- 「＋新主目标」：**种植唯一入口**（转世界管理；种下即激活为当前树）；
- 空树引导态：当前领域无树→「开始分解你的目标」引导。

**输入 → 输出**
- 读：领域表/树列表/激活态；写：激活切换（经变更链）；种植/删树请求。

**承接**：M11 · A7（删后回退反映在此）· R31/R40。

**验收**
- 切换后画布内容=新激活树（选中态清空无残留）〔手〕；空树引导不崩〔手〕。

**边界**：不做领域编辑（增删改名在领域数据管理）；不渲染 3D。
**待定**：单岛模型下「领域」在切换器中的呈现（分组下拉 or 平铺）。
