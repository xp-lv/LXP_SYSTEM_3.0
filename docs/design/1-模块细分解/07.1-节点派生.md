# 07.1 · 节点派生 · 全定义

> 父模块：[数据](./07-数据模块.md) · 状态：〔已定义〕

**是什么**：任务树自底向上的汇总计算——呈现层的一切读数来源。

**行为**
- 载入后/每次变更后**全量重算**（树规模小，不做增量）；
- 派生清单（《6》§C）：`H`（工时汇总）· `pct`（完成工时/总工时）·
  **`bare`（断梢=叶子且未完成且无排期）** · `buckets`（done/overdue/assigned/floating）·
  `redCount`（逾期任务数）· `overdue` 重算（按 R16 时效）；
- **派生永不持久化**（G5）；空树防护（H=0 → pct=0，不出 NaN）。

**输入 → 输出**
- 读：任务树原子字段；提供：派生字段（挂在节点上，供树/信息/今日读取）。

**承接**：T6（派生必须先于一切读）· R16/R28 · 验收 C7/G5。

**验收**
- 派生与手算一致（构造用例覆盖 bare/buckets/pct/redCount）〔自〕。

**边界**：不做物候推导（旧 ph 已废弃）；不判断逾期检测时机（A4/A5 调它）。
**待定**：无。
