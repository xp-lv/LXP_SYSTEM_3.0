# 01.2 · 世界管理 · 全定义

> 父模块：[岛屿](./01-岛屿模块.md) · 状态：〔已定义〕

**是什么**：树的种植/移除/激活管理与领域数据分组管理的世界侧执行者。

**行为**
- **种植**：接宏观页请求 → 分配坑位（墓碑复用）→ 新树=断木桩态（秃干+顶红光）；
- **移除**：接删树请求（确认在调用方）→ 释放坑位（标记复用，不留可见痕迹）→ 触发重建；
- **激活**：单击树 → 激活该树（相机聚焦）；
- **激活回退链**（A7）：删激活树后自动回退（全文以《3》A7 为准）；
- **领域分组**：领域的增删改名（纯数据操作；世界里零呈现）——UI 入口=宏观页树切换器（03.5）；
- 全岛树总量上限（R39 ⚖️）：满员时「＋新主目标」禁用+原因提示（"全岛已满 N 棵——先完成或删除一棵树"）。

**输入 → 输出**
- 读：领域表、树列表、激活态；写：坑位占用、领域表、激活态（经变更链存档）。

**承接**：W4（单击树激活）· M11（种植/删树入口）· A3/A7 · T8 删树序列 ·
R30/R31/R35⚖️/R37/R39⚖️ · 删领域时其树的处置 ⚖️（《6》§D）。

**验收**
- 满员时种植入口引导〔手〕；回退链各分支可达空态〔手〕。

**边界**：不做确认 UI（调用方）；不管网格（岛体建造）；不直接改任务数据。
**待定**：R39 上限数字 · D3 删领域时树的处置 · R35 领域操作入栈否。
