# 10.5 · 风 · 全定义

> 父模块：[环境](./10-环境模块.md) · 状态：〔已定义·demo 验证〕

**是什么**：全场风场——树与草摇曳的驱动源。

**行为**
- 全局两个量：时间流 + 阵风强度（多频正弦叠加的缓慢起伏）；
- 受体与权重：树（顶点级：干小→臂中→梢大→指线最大）、草（基部固定梢部摆）；
- **影子通道同步摆**（颜色通道与深度通道同一位移——防影子错位暗带）；
- 今日星空态、星球态下风照常（周树/无树时自然无受体）。

**输入 → 输出**
- 提供：每帧的风 uniform（全体受风材质共享）。

**承接**：A9 每帧组 · 02.2 木质外观（受体）· 风摆参数以 demo 实现为准。

**验收**
- 树与影同步摆（无错位暗带）〔视〕；阵风有起伏不是匀速摆〔视〕。

**边界**：不接收业务；不做定向风/风暴。
**待定**：无。
