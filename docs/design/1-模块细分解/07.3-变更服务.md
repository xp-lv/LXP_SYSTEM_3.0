# 07.3 · 变更服务 · 全定义

> 父模块：[数据](./07-数据模块.md) · 状态：〔已定义〕

**是什么**：**全系统唯一写入口**——任何模块改任务数据必须经此（红线 G1）。

**行为**
- 操作集：增删改/改名/落月/落周/落日/移出/换月/补点/排序/临时/批量逾期；
- 每次变更执行：校验（R1–R33 的规则在此落地）→ 级联（落日补齐周月 R14、
  移出月清空周日 R7、换月删子树 R8…）→ 打 undo 快照（按 R34/R35）→
  派生（07.1）→ 通知呈现层 → 存档（07.5）；
- **顺序契约（T6）**：派生完成前任何读路径不得返回新数据；
- 通过注册回调通知渲染（不直接 import 渲染模块）。

**输入 → 输出**
- 读：任务树+规则参数；写：任务树原子字段（唯一合法写者）。

**承接**：T6/T2/T7/T8 · R1–R36 的执行点 · 验收 G1/G2。

**验收**
- 绕过本服务的写路径=0（代码断言）〔自〕；级联规则逐条用例〔自〕。

**边界**：不做确认 UI（调用方）；不管渲染细节。
**待定**：R8 makeup 处置 · R35 领域操作入栈。
