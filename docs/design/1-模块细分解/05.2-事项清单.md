# 05.2 · 事项清单 · 全定义

> 父模块：[今日](./05-今日模块.md) · 状态：〔已定义〕

**是什么**：当日任务的执行清单（模块拼接式卡片）。

**行为**
- 卡片=环（0/1 二值；有草稿分解按子项比例）+「补 MM-DD」角标（补点）+「程」胶囊（临时）；
  副标题=**树色圆点 + 树短名**（省略领域层，hover 显完整路径）；临时任务的「程」胶囊替代副标题位置；
  **环随完成用绿色填充**（勾选比例/完成态=绿色，与执行区同一完成语言）；
- **执行中联动标识**：被提入执行区的任务卡，左侧 2px 绿色呼吸边 + 副标题追加「⚡ 执行中」；
  移出执行区（×/完成）即熄灭——清单与执行区的状态纽带（数据源=执行区会话态，不持久化）；
- **勾选完成**：完成仪式（环充能→划线→脉冲→果粒迸发→沉入已完成组，T16）；
  已完成组默认折叠可展开（**组头吸顶**：滚动时「今日任务/已完成」组头 sticky+半透明模糊；
  展开/收起 200ms 高度过渡）；再点环撤销；
- 拖动自由排序（`order` 持久化）；**拖动实时让位**：移动时其余卡片平滑让位（~80ms transform）、
  目标插入位显示高亮间隙线，松手即所见顺序；
- 「＋临时」=新增临时任务并落到今天（全局日程池）；
- **辅助分解**：草稿子项（checklist，不入树不带工时；父任务由子项全勾自动完成 R28）；
  **子项完成=正式 ✓ 按钮**（未勾空环描边→勾选绿填充+白✓+划线，非勾选框）。

**输入 → 输出**
- 读：当日清单（含补点/临时）；写：progress/order/checklist/temps。

**承接**：T1/T2/T3/T4 · T16 · R25/R26/R28。

**验收**
- 勾选→仪式→沉组、再点撤销〔手/视〕；排序持久化〔自〕；
  分解后只能勾子项、全勾父自完成〔自〕；
- 执行中卡片带呼吸边+「⚡ 执行中」，移出即熄灭〔手/视〕；
- 副标题=树色点+树短名（hover 全路径）；临时卡带「程」胶囊〔手/视〕；
- 长列表滚动时组头吸顶不迷路；已完成组展开/收起有高度过渡〔手/视〕；
- 拖动时其余卡实时让位、插入位有间隙线，松手顺序=所见〔手/视〕。

**边界**：只做勾选/排序/临时/草稿——改工时与移出落日回周画布（单一心智）。
**待定**：无。
