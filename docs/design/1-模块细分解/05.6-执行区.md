## 定义与边界

- **定义**：今日页左上角（顶带下方、任务清单左侧空隙）的半透明浮动面板。
  用户点击清单中的任务卡片（非环）→ 任务提升到执行区，标记为"正在执行"。
  可同时执行多个任务（无上限）。执行区显示动态卡片+特效，支持草稿分解。
- **边界**：仅今日页显示（其他视图不渲染，但状态保留）；**入档状态（v12）**——
  `data.exec` 随存档写入并经云同步到服务器 data.json（多设备一致），刷新/切视图/换设备不丢；
  不改变任务数据（progress/assignD 等不受影响）——执行是瞬时行为，完成才是数据变更。

## 布局结构

```
┌─────────────────────────────────────────────────┐
│ ⚡ 正在执行                                      │
├─────────────────────────────────────────────────┤
│ ┌─────────────────┐  ┌──────┬──────┬─────→     │
│ │ 📖 词汇          │  │☐ 背50│☐ 复习│ (列多横向  │
│ │ ⏱ 3m             │  │  [✓] │  [✓] │  滚动)    │
│ │                  │  ├──────┼──────┤           │
│ │ ▓▓▓▓░░░ 1/3     │  │☐ 真题│      │           │
│ │                  │  │  [✓] │      │           │
│ │ [＋ 分解(整行)]   │  └──────┴──────┘           │
│ │                  │   （面板定宽；先竖后横：列内  │
│ └─────────────────┘    上下 2 个，满 2 向右增列） │
│                                                  │
│ 主卡片（左）＋ 子项陈列面板（右，纯陈列）          │
└─────────────────────────────────────────────────┘
```

- **主卡片**（左侧）：**定高 112px、定宽 160px，内部恒定三槽**（槽位与尺寸两态完全不变）：
  - **头槽**（弹性）：任务名（最多两行）+ ×；已分解时计时器以小字缩至**名前左上角**；
  - **中槽**（固定高度）：未分解 = 计时器（14px）；已分解 = **分段进度条 + n/m**
    （占据原计时器位，两态互换同高）；
  - **底槽**（固定高度）：未分解 = **[✓ 完成] 与 [＋ 分解] 并排**（等宽）；
    已分解 = 完成键消失，**[＋ 分解] 原位横向拉满整行**（位置不变仅变长）；
  - 点击 [＋ 分解] → **直接在子面板尾部新增一个空子任务块（编辑态）**——
    名字位置就地输入，Enter 落名并追加下一块（T9e），Esc/空值失焦收回空块；
    **主卡不出现任何输入行、外框不因分解改变**。
- **子项面板**（右侧）：**纯陈列，无独立输入框**；与主卡片并排，
  **宽度按内容自适应（max ~182px）——1 列即收窄不留空带，≥2 列铺满（内宽 164=
  子卡 80×2+4 缝）**；
  **子卡定高 56px——与主卡 112 构成长宽严格 2:1（160:80 × 112:56）**；
  排布**先竖后横**——每列纵向 2 个子项卡（两行 56×2+4=116 与主卡对齐）；
  **超出 4 个（2 列）不分栏滚动，改分页呈现：无横向滚动条**（网格 `overflow:hidden` +
  整页平移 200ms），**面板底缘一枚小按钮「n/m ›」循环翻页**（末页再点回首页）；
  **空面板显示 2×2 ghost 虚线占位格（80×56） +「点击分解添加子项」**
- **空态收窄**：无执行任务时整块收窄为一条**药丸提示条**
  （「⚡ 点击右侧清单任务开始执行」，呼吸绿边）；首个任务进入时展开为完整面板（300ms 高度过渡）
- **多任务竖向平铺**：每个执行任务各成一组（主卡+子面板）**完整展开、自上而下平铺**；
  无手风琴/摘要卡；组数多时面板纵向滚动；各组子项分页互相独立
- **面板折叠钮**：标题行右侧「–」可整体折叠执行区（仅剩标题行），会话级记忆

## 主卡片两种状态

| 状态 | 主卡片显示 | 触发条件 |
|---|---|---|
| **未分解**（无子项） | 任务名 + ⏱ 计时器 + **[✓ 完成] 与 [＋ 分解] 并排**（等宽） | checklist 为空 |
| **已分解**（有子项） | 任务名 + ⏱ 计时器 + **进度条**（子项勾选比例）+ **[＋ 分解] 独占整行** | checklist 非空；完成按钮消失 |

> 分解与子项是同一入口：点 [＋ 分解] 即展开输入行加子项。
> 分解后**不能一键完成**——必须逐个完成子项（R28 checklist 语义），
> 全部子项完成后父任务自动完成 → 金色粒子 → 执行区自动移出。

## 数据模型（v12：入档 + 云同步）

```
data.exec = {                                   // 存档字段（schema v2 新增，随文档同步）
  items: [
    {
      nodeId: number,        // 任务节点 id
      startedAt: number,     // Date.now()（恢复后计时以 startedAt 续算）
      decomposed: boolean,   // 是否已展开子项面板
      page: number,          // （预留，当前恒 0）
    }
  ],
  collapsed: boolean          // 面板折叠态
}

写入时机：加入/移出/自动移出、[＋分解] 展开、面板折叠切换——经 touch() 变更广播
（07.3 单通道）→ main 存档 + 防抖推送服务器（多设备以最后推送为准，与全局同步语义一致）。
恢复时机：页面加载后首次进入今日页——过滤"节点已不存在或已完成"的陈旧项。
editing 不入档（重载后输入框收回）；历史日视角/离开今日页只隐藏不清空。

// 草稿子项沿用节点自身的 checklist 字段（已持久化）
// 子项完成 → checklist[i].done = true → 走 updateTask 变更链
// 全部 done → 父 progress=1（R28）→ 执行区自动移出
```

## 视觉规格

- 执行区面板：`position:fixed; top:64px; left:16px; z-index:45; width:~520px; max-width:44vw`
- **空态药丸**：高 ~32px、呼吸绿边、半透明底；
  非空展开为完整面板（高度过渡 300ms）；标题行右端「–/▸」折叠钮（会话级）
- 主卡片：**160 × 112（定宽定高，两态不变）**；恒定三槽：
  头槽（名两行 clamp，弹性吸余高；分解态名前多一枚 10px 小字计时器）
  → 中槽（固定 20px：未分解=计时器 14px / 已分解=分段进度条+n/m）
  → 底槽（固定 24px：未分解=[✓ 完成][＋ 分解] 并排 / 已分解=[＋ 分解] 原位拉满）；
  呼吸绿光**只动 border-color**（外阴影固定一层）；hover 仅 1px 浮起不叠新阴影
- **计时器**：mm:ss（≥1h 为 H:MM:SS），`tabular-nums`，秒位跳动 0.98→1 轻脉冲
- 子项面板：与主卡片**水平并排**（flex row），**宽度 `max-content`、上限 ~182px**
  （border-left 2 + padding 8×2 + 内宽 164=两列满幅；单列时自动收窄无空带）
- 子项网格：**先竖后横**——`grid-auto-flow:column; grid-template-rows:repeat(2,56px)`，
  `grid-auto-columns:80px`（**子卡 80×56，与主卡 160×112 长宽严格 2:1**）；
  视口 `overflow:hidden` **无滚动条**；每页 = 2 列（164px），整页 `translateX` 平移过渡 200ms；
  **翻页小按钮**：面板底缘居中「n/m ›」（仅多页时出现；末页再点回首页）
- 子项卡：**80 × 56（定高）**；**名称 11px 两行 clamp + hover title 全文**；
  done 态透明度 .55 + 划线
- **空面板**：2×2 **ghost 虚线占位格（每格 80×56）** + 文案「点击分解添加子项」
- 子项 ✓ 钮：**与主卡 [✓ 完成] 同规格族的实体钮**（同描边/微底/圆角 6px/hover 浮起，
  ~24×20px）；勾选=实心绿+白✓
- 删除 ×：主卡/子项/摘要卡**同一规格**——12px 字号、≥16px 热区、右上、hover 变红
- **分段进度条**：按子项数等分格（格间 2px 缝），勾一格亮一格（深绿→亮绿渐变），
  n/m 芯片在条右侧
- **编辑态子块**：虚线描边子卡，名字位置为透明输入（占位"子项名…"，
  11px 与成品名同规格）；Enter 落名即转成品卡

## 与其他规则的关系

- **R28（completedAt）**：执行区点 [✓ 完成] 或子项全部勾选自动完成时，`updateTask` 写入 `completedAt=Date.now()`；
  今日页撤回（点环取消完成）检查 `completedAt ≥ 今天 00:00`（R28 撤回边界）。
- **R33（历史周只读）**：执行区仅在今日页可用；历史日视角不显示执行区。
- **05.1（浮岩舞台）**：执行区是 DOM 层，不影响 3D 浮岩舞台/虚拟周树。
- **《6》§B（checklist）**：子项数据=节点的 checklist 字段（已持久化），
  在执行区和清单面板双端可编辑（同一数据源）。
