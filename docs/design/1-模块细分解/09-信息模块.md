# 09 · 信息模块 · 完全定义

> 《0-模块分解》模块 9。面板与读数：一切"看"的出口（只读展示，动作回调注入）。

## 定义与边界

- **定义**：树选择框、任务大纲、顶栏读数、悬停详情卡、小地图、提示层。
- **边界**：只读派生数据；不写数据；不持有相机（定位/进入动作转交交互/星球模块）。

## 最小功能模块

### 树选择框
- 当前领域的树列表（名+%）；点行=激活该树；
- 领域分组呈现（领域是数据分组，这里是它在世界侧的唯一可见处之一）。

### 任务大纲
- 激活树的层级细节：状态点（红=断梢/绿=细枝/金=完成）+ 工时 + 进度 + 断梢标注；
- **点条目=进入该节点的星球视图**（星球的第二入口）。

### 顶栏读数
- 进度徽章五档（荒芜→圆满，色随档）+ 总%；
- 断梢数 / 完成数 / 过期数 / 任务数（口径=派生：bare 计数、redCount、leafCount）；
- ⚖️ 是否恢复"欠约束工时"读数。

### 悬停详情卡
- 悬停树上元素/果 → 该任务档案：标题、路径（目标›…›任务）、工时、排期、状态；
- 措辞与新三态对齐（不再用旧物候词）。

### 小地图
- 岛的俯瞰：树点（激活高亮）+ 断梢红光位 + 相机取景框。

### 提示层
- 完成反馈 toast（「XX」全部完成 · 长出叶团）；
- 路径面包屑、图例（图例只讲三态语言）。
