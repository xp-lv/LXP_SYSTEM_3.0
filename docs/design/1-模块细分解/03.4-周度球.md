# 03.4 · 周度球 · 全定义

> 父模块：[顶层目标分解](./03-顶层目标分解模块.md) · 状态：〔已定义〕

**是什么**：月详情底部的周导航与排周入口（宏观↔微观的桥）。

**行为**
- 该月 W1–W5 球悬浮画布底部中央；
- 每球=周标签+任务数圆点（每任务一枚、颜色=目标色、≤7 枚、空周无点、含「本周」标记）；
  不显示任务名与工时；
- **拖月度任务入球=落周**（幽灵+高亮+回弹，圆点即时增减）；
- **点击球=跳该周的微观规划**（该周成为选中周；飞移动画 T15 是纽带）；
  拖拽=排周、点击=跳转，互不冲突。

**输入 → 输出**
- 读：该月各周任务分布；写：assignW（经变更服务）；导航事件（跳周）。

**承接**：M8/M9 · R10 · T15。

**验收**
- 圆点数与该周任务一致（含已分解部分）〔自〕；点球跳周且选中周正确〔手〕。

**边界**：不是任务清单（不弹浮卡）；不管改排（重拖即改写）。
**待定**：无。
