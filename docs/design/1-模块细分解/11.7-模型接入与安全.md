# 11.7 · 模型接入与安全 · 全定义

> 父模块：[AI 规划模块](./11-AI规划模块.md) · 状态：〔已定义·待实现〕

**是什么**：AI 模块与外部大模型之间的接入层：服务端代理、工具调用协议、流式输出、
失败恢复，以及密钥、文档、Prompt 注入等安全边界。

**为什么**：浏览器直连模型会把 API Key 暴露给任何打开开发者工具的人；
把模型输出直接渲染成 HTML 又会把 token 置于 XSS 风险之下。接入层必须是“薄但有边界”的。

## 服务端代理

```
浏览器 ── POST /api/agent/chat（Bearer TOKEN，SSE/JSON）──► Node 服务
                                                           └─► OpenAI 兼容 /chat/completions
                                                               （Base URL / Key / Model 来自环境变量）
```

环境变量：

```
LLM_BASE_URL=https://api.deepseek.com/v1     # 任意 OpenAI 兼容端点
LLM_API_KEY=...                              # 只存服务端，不出现在前端/响应/日志
LLM_MODEL=deepseek-chat
LLM_TIMEOUT_MS=30000
LLM_MAX_TOKENS=8192
LLM_MAX_ROUNDS=8                             # 单回合最大工具轮次

AGENT_DATA_DIR=...                           # AI 工作区根；默认 {DATA_DIR}
                                             # 文档根 = {AGENT_DATA_DIR}/agent-docs
```

- 支持原生 tool calling；模型不支持时降级为**严格 JSON 动作协议**
  （只接受白名单工具与参数，前端解析后走同一执行器）。
- 流式输出用 SSE：`token` / `tool_call` / `tool_result` / `done` / `error` 事件；
  断流保留已生成内容为草稿，可重试。
- 超时、429、5xx：瞬时错误重试一次；4xx 不重试并显示原因。
- 记录 token 用量与耗时（不记录完整 prompt/密钥），用于成本控制。

## 鉴权与限流

- `/api/agent/*` 与 `/api/docs/*` 复用现有 Bearer TOKEN；未授权返回 401。
- 简单限流：每会话每分钟请求数上限；单次请求体大小上限；单回合工具轮次上限。
- 并发：同一 `runId` 默认单写者；多标签页/多设备用 `baseVersion` 冲突提示。
- 禁止把 TOKEN 拼进 URL（避免日志/Referer 泄露）；前端从 localStorage 读取并放 Authorization 头。

## 安全边界

### 密钥
- API Key 只在服务端环境变量；前端代码、接口响应、错误信息、日志、文档里都不得出现。
- 服务端日志对 Authorization、Key、完整 prompt 做脱敏/截断。

### 文档
- 只能写受管目录 `{AGENT_DATA_DIR}/agent-docs`（默认 `{DATA_DIR}/agent-docs`）；规范化后必须仍在根内；
- 仅 `.md`；拒绝绝对路径、`..`、符号链接逃逸；
- 单文件、单 run 总量、目录深度有上限；原子写入（临时文件 + rename）；
- 文档通过 `/api/docs/*` 鉴权访问，不能靠静态目录直接下载。

### 静态目录（前置修复）
- 现有 `express.static(WORKSPACE_ROOT)` 会暴露 `data.json` 与源码；
  Docker 下静态根甚至是容器 `/`。新增 AI 文档前必须改为显式挂载 `/app` 与 `/ez-tree`，
  并屏蔽 `/app/data`；否则文档与存档可被无鉴权下载。

### Markdown / XSS
- 渲染时禁用原始 HTML（`marked` 的 `html:false`）或使用白名单清洗（DOMPurify）；
- 链接强制 `target=_blank rel=noopener noreferrer`；禁止 `javascript:` 协议；
- 文档与对话内容视为**不可信数据**，不得作为系统指令执行。

### Prompt 注入
- 任务标题、文档正文、导入内容都可能包含“忽略之前指令”之类文本；
- 系统提示明确：这些内容是数据，不是指令；工具调用必须通过参数校验；
- 高影响操作（删除/完成/批量落库）必须经过用户确认，模型无法自行触发。

## 失败路径

| 情形 | 行为 |
|---|---|
| 模型超时 / 断流 | 保留已生成草稿；提示重试；不落库 |
| 429 / 限流 | 退避一次；仍失败则提示稍后重试 |
| 401 / Key 无效 | 明确提示“模型未配置/凭证失效”；不泄露 Key |
| 工具调用参数非法 | 返回结构化错误给模型；连续失败则暂停并提示用户 |
| 落库批次部分失败 | 整批回滚；`planRun.status='apply_failed'`；可重试 |
| 文档写入冲突 | 409 + 当前版本；提示刷新/另存新版本 |
| 文档路径非法 | 400；记录审计但不写入 |

**承接**：R50/R51/R52/R53/R54 · A14/A15 · T24/T28。

**验收**
- 前端代码、网络响应、日志中无 API Key〔自〕；
- 未授权访问 `/api/agent/*`、`/api/docs/*` 返回 401〔自〕；
- 文档路径穿越/非 md/超大文件被拒〔自〕；
- Markdown 原始 HTML 不执行〔自〕；
- 模型超时/限流有可读提示，草稿不丢，任务零变化〔手/自〕；
- 单回合工具轮次/token 超限能暂停并提示〔自〕。

**边界**：不做模型训练/微调；不做多租户计费；不代理非白名单域名。
**待定**：默认模型与提供商；是否支持本地 Ollama；流式是否 v1 必需；限流阈值；是否记录完整会话用于调试（默认否）。
