# 01.3 · 树坑布局 · 全定义

> 父模块：[岛屿](./01-岛屿模块.md) · 状态：〔v2 · 2026-10-13 简化为固定六坑〕

**是什么**：岛上树坑的固定位置表——中心 1 棵 + 外围正五边形 5 棵，共 6 棵上限。

## 布局

```
            ● T1（北）
         ／      ＼
       ● T5        ● T2
        |    ● T0    |
       ● T4        ● T3
         ＼      ／

    T0 = 中心 (0, 0)，最高峰 h=52
    T1~T5 = 五边形，半径 430，从正北起每 72°
    坑高 h=38，坑半径 r=170
```

## 规则

| 规则 | 说明 |
|---|---|
| **TREE_CAP = 6** | 中心 1 + 五边形 5，不按领域分 |
| **墓碑制（R37）** | 删树→坑位置空待复用；活树永不移动 |
| **分配顺序** | 第 1 棵→中心，第 2-6 棵→五边形（从正北顺时针） |
| **复用** | 优先填空坑（不按领域），中心空了先填中心 |
| **领域无关** | 坑位不关联 domainId；树的领域归属在树根节点上 |

## 与现有模块的关系

| 模块 | 影响 |
|---|---|
| slots.js | `FIXED_SLOTS` 硬编码 6 个坐标；`allocateTreeSlot` 顺序分配 |
| island.js | 纯净版——移除扇区着色，回归原版 |
| world.js | `allocateTreeSlot(island)` 不传领域参数 |

## 验收

- 第 1 棵树在岛中心；第 2-6 棵在五边形顶点〔视〕
- 6 棵满员后种植入口禁用〔手〕
- 删任意一棵后其余树位置逐帧不变〔自〕
