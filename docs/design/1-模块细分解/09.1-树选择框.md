# 09.1 · 树选择框 · 全定义

> 父模块：[信息](./09-信息模块.md) · 状态：〔已定义·demo 验证〕

**是什么**：当前领域的树列表与切换入口（领域在世界侧的唯一可见处）。

**行为**
- 标题=当前领域名；列表=该领域的树（名+进度%）；
- 点行=激活该树（转世界管理；世界/大纲/规划页跟随）；
- 激活行高亮；领域切换（规划页/数据侧）后列表即时刷新；
- 空领域显示空态。

**输入 → 输出**
- 读：领域表/树列表/激活态/每树 pct；动作转交，无写。

**承接**：W8 · 树切换器（03.5）是它在规划页的对应物。

**验收**
- 点行激活正确、各面板同步无残留〔手〕；随领域切换刷新〔手〕。

**边界**：不做领域编辑；不显示任务细节（大纲的事）。
**待定**：无（已定：仅显示当前领域的树；跨领域切换走宏观页树切换器。）
