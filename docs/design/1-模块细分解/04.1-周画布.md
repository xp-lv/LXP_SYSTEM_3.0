# 04.1 · 周画布 · 全定义

> 父模块：[周度目标分解](./04-周度目标分解模块.md) · 状态：〔已定义〕

**是什么**：周任务的分解编辑与工时填写画布（工时在系统的起点）。

**行为**
- 结构：「本周」根→目标分组（跨树汇总，含「日程」组）→周任务（组内递归展开）；
- 悬停＋分解：原地命名，`lvl=week`，默认 2h；**两层封底**（R3）；
- 行内点改工时（0h 显琥珀「填工时」）；
- 与目标画布同构（同一可复用分解模块）：无限画布/平移/初始居中。

**输入 → 输出**
- 读：本周任务（assignW/makeup 落本周）+日程池；写：结构/hours（经变更服务）。

**承接**：K1/K2 · R1/R3/R22 · T17。

**验收**
- 两层后无＋〔手〕；工时点改即时反映到容量与派生〔自〕。

**边界**：不做跨周拖拽（R11）；不落日（泡泡的事）。
**待定**：无。
