# 04.4 · 临时任务 · 全定义

> 父模块：[周度目标分解](./04-周度目标分解模块.md) · 状态：〔已定义〕

**是什么**：日程式临时任务的全局日程池管理（不入任务树）。

**行为**
- 「＋临时任务」弹窗：名称+工时必填（R26）；
- 存于全局日程池 `temps[]`：不挂树、不属领域、世界与宏观不可见；
- 周画布归入「日程」组（当前/未来周可见）；可直接拖入泡泡落日；
  落日后进入当日清单；悬停×删除；
- 今日页「＋临时」=新增并直接落到当天（或查看中的日，05.4）——**order 取当日清单最小值-1 置顶呈现**
  （清单按 order 升序；修复过"无 order 落最底"的问题）。

**输入 → 输出**
- 读/写：temps[]（经变更服务；入 undo 栈 R34）。

**承接**：K3/K9 · R26/R27 · 数据契约《6》临时任务结构。

**验收**
- 未落日临时只在周度树可见；落日后进清单〔手〕；删除即时生效〔手〕。

**边界**：不走分解链；无级别递进（永远 temp）。
**待定**：无。
