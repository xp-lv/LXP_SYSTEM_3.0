# 09.4 · 悬停详情卡 · 全定义

> 父模块：[信息](./09-信息模块.md) · 状态：〔已定义〕

**是什么**：指向哪里、显示那个任务的档案（世界/星球通用）。

**行为**
- 触发：悬停树上元素（枝/指线/叶团）、星系球、今日果（转交悬停态）；
- 内容：标题、路径（目标›…›任务）、工时、排期（待排/已排日）、状态
  （措辞=三态：断梢/已排期/完成）；
- 固定屏幕角位（不跟鼠标，稳定可读）；离开/切换即更新；悬停锁定时可钉住；
- 纯读——卡片上无任何操作按钮。

**输入 → 输出**
- 读：悬停命中节点的派生与排期；纯读。

**承接**：W7、P5 的信息侧 · 悬停锁定（旧 hoverLock 语义收编）· 验收 C9。

**验收**
- 卡内容与该任务数据一致〔手〕；悬停切换无闪烁残影〔手〕。

**边界**：不做点击动作（点击走拾取路由）；不显示同级/子级列表。
**待定**：无。
