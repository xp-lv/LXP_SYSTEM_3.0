# 03.1 · 目标画布 · 全定义

> 父模块：[顶层目标分解](./03-顶层目标分解模块.md) · 状态：〔已定义〕

**是什么**：主目标→二级→三级的分解编辑画布（可复用分解模块的宿主）。

**行为**
- 层级树呈现与编辑：悬停＋加子级（Enter 连续、空名失焦即撤销）、双击改名、
  悬停×删子树；
- 无限画布：四向平移、初始居中、内容不足仍留余量；
- 节点信息行**只有落月标记**（「9月·10月」）——无工时（R22）；
- 3 级封底（R2）。

**输入 → 输出**
- 读：当前激活树；写：任务结构（经变更服务）。

**承接**：M1/M2/M3/M12 · R1/R2 · 入场编排 T17。

**验收**
- 三级后无＋；空名新建不留垃圾节点〔手〕；画布四向平移+视角保持〔手〕。

**边界**：不显示工时；不做分配（拖去月卡是月度分配的落点）。
**待定**：无。
