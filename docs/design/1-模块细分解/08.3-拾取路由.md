# 08.3 · 拾取路由 · 全定义

> 父模块：[交互](./08-交互模块.md) · 状态：〔已定义〕

**是什么**：把"点到了什么"翻译成系统动作的路由表（世界只读的执行者）。

**行为**
- 命中检测：从渲染层注册表取候选（树网格/星系球/落果/岛面）；
- **路由表（世界视图）**：

| 点到 | 动作 | 转交 |
|---|---|---|
| 树（单击） | 激活该树+聚焦 | 世界管理 |
| 树（右键） | 进入星系 | 星球模块 |
| 星系球（单击） | 下钻/返回 | 星球导航 |
| 落果/落叶堆 | 补点选择器 | 今日·补点系统 |
| 岛面 | 无动作（只读 R40） | — |

- 悬停：命中→详情卡（信息模块）+指针样式；
- 拖拽落点（画布侧）：月卡/周度球/泡泡的 drop 由各页面自持，本模块只管 3D 场景。

**承接**：W4/W6/W7、P2/P3、T5 · R40/R11 · 验收 C8。

**验收**
- 路由全表命中正确对象〔手〕；岛上无任何编辑动作可达〔自〕。

**边界**：不写数据（动作全部转交）；不渲染高亮（呈现层的事）。
**待定**：世界→宏观规划的直达入口——点树现仅激活（W4），进规划只剩顶栏导航（G1）；
是否恢复"点树=激活+进规划"或增加双击直达，待拍板。
