# 06.3 · 星球标注 · 全定义

> 父模块：[星球](./06-星球模块.md) · 状态：〔旧实现可收编〕

**是什么**：星系里每颗球的名称标签与连线。

**行为**
- 每颗球带名称标签（任务标题）；
- 标签屏幕空间互斥排布（重叠者按优先级隐藏：悬停>中心>行星>卫星）；
- 标签贴球体上缘外（沿相机 up 方向偏移，任意视角不压球）；
- 行星↔卫星弧线连线（贝塞尔弓形+端点渐隐）；
  悬停组连线点亮；
- 新球入场弹性生长（标签随缩放）。

**输入 → 输出**
- 读：球位置/半径/标题/悬停态；纯呈现，无写。

**承接**：P5 · 旧 app planet.js 有完整实现（收编+按新视觉语言调色）。

**验收**
- 标签不重叠不压球〔手/视〕；连线随公转实时更新〔手〕。

**边界**：不做内容（任务详情走悬停详情卡）。
**待定**：标注配色归入新视觉语言（星球视觉整体待设计）。
