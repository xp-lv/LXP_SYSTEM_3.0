# 10.3 · 天空 · 全定义

> 父模块：[环境](./10-环境模块.md) · 状态：〔已定义·demo 验证〕

**是什么**：天穹、太阳、云、星空的呈现层。

**行为**
- **天穹**：渐变球（顶/中/底三色随时段联动）+ 太阳方向辉光；
- **太阳**：辉光贴片随主光方位移动（时段切换时划过天空）；
- **云**：环带云缓慢漂移（循环回绕），色调随时段；
- **星空**：固定星点球，夜晚淡入、昼间透明；

**输入 → 输出**
- 读：时段预设状态；纯呈现（每帧）。

**承接**：T12（联动缓动）· 参数以 demo 实现为准 · 验收 C10。

**验收**
- 时段切换天穹/太阳/云/星联动一致无跳变〔视〕。

**边界**：不做天文精确（风格化）；不可交互。
**待定**：无。
