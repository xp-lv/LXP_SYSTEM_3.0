# 05.4 · 日视角切换 · 全定义

> 父模块：[今日](./05-今日模块.md) · 状态：〔已定义〕

**是什么**：今日页按天查看的导航（周↔日双页切换，日泡泡为纽带）。

**行为**
- 入口：周规划七日泡泡可点击→进入该日视图（泡泡飞移 T15）；
- 日视角=今日页参数化到「当前查看日」（默认真今天）：
  顶带日期/负载、清单、总进度环、「＋临时」落日均跟随；
  周树/落果/落叶堆按**该日所属周**呈现；
- 底部日条（与周规划同源泡泡陈列）：选中日描边高亮、真今天金色；
  **再点当前日=回周规划**（回到该日所属周）；点其他日=切换日视角；
- 顶栏「今日」永远重置回真今天（不残留日视角）。

**输入 → 输出**
- 读：查看日参数；写：导航事件。

**承接**：T6/T7/T8 · T15 · R32（周边界影响呈现）。

**验收**
- 日视角各读数跟随查看日〔手〕；再点当前日回周、导航重置回今天〔手〕。

**边界**：未来日/历史日的**编辑边界**沿用对应周的规则（历史周日=只读）。
**待定**：未来日（排了还没到）清单的呈现口径。
