# 02.2 · 木质外观 · 全定义

> 父模块：[树](./02-树模块.md) · 状态：〔已定义·demo 验证〕

**是什么**：给骨架覆上树皮的质感与受光表现（蒙皮层）。

**行为**
- 沿骨架折线扫掠变径管：贴图顺枝走向（无人字纹）、凹凸、接缝处顶点 AO；
- 子枝沉入母枝（分叉衔接无缝）、断口自然收尖；
- 受光材质（昼昏夜随环境联动）；
- 风摆按层级加权（干小梢大），投影与影子通道同步摆。

**输入 → 输出**
- 读：骨架折线+半径信息（树形生成）；
- 提供：整树/逐枝的木质网格（激活树逐枝=可拾取单位，远景树合并=单网格）。

**承接**：风=环境模块风场 · 验收 C2（夜景受光）· 参数以 demo 实现为准。

**边界**：不决定树形；不管三态（红光/叶团另挂）；不贴业务。
**待定**：无。
