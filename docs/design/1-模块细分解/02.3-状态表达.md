# 02.3 · 状态表达 · 全定义

> 父模块：[树](./02-树模块.md) · 状态：〔已定义·demo 验证〕

**是什么**：树上的三态呈现与完成动画——全系统共用的视觉语言。

**行为**
- **断梢红光**：自发光红核+呼吸光晕，相位按位置错开；夜晚成灯；
- **日梢指线**：已排期末梢的短果枝（point 收尖）；
- **完成叶团**：分叉下全部完成→绿色聚合叶团（大小∝工时），easeOutBack 入场；
  取消完成→收缩收回；**骨架永不因状态改变**；
- 秃干+顶红光=完全未分解目标的默认态。

**输入 → 输出**
- 读：状态映射的判定结果（bare/有排期/分叉全完成）+ 工时（叶团大小）；
- 提供：三态网格与动画注册（呼吸/生长/收回）。

**承接**：A1/A2 · T1（呈现态机）/T7（级联）/T10/T11 · R28/R29 ·
验收 C2（三态转换/夜景）。

**边界**：不做判定（状态映射的事）；不改骨架。
**已定 D1=A（不上树）**：树上只有红光/指线/叶团三态，时间信息交给今日页和顶栏——保持三态语言封闭性。
