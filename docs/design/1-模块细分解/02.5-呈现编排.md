# 02.5 · 呈现编排 · 全定义

> 父模块：[树](./02-树模块.md) · 状态：〔已定义〕

**是什么**：决定每棵树以什么精度呈现、重建与销毁的编排者。

**行为**
- **激活树**：逐枝独立网格（每枝=拾取单位，点树/悬停/星球锚点都来自它）；
- **其余树**：远景简版（合并单网格；点树=激活）；
- 树集合变化（种植/删除/激活切换/数据变更）→ 重建；重建=销毁旧网格再建新
  （确定性保证视觉无跳变）；
- 今日虚拟树也走同一编排（独占态下只呈现周树）。

**输入 → 输出**
- 读：激活态 + 全部树数据；提供：场景中的树网格集合 + 拾取注册表。

**承接**：W4/W7（拾取源）· T3/T8/T9（重建时机）· R38（重建后视觉一致）·
验收 G4（同档同树逐字节一致）。

**边界**：不管哪种树形（树形生成/状态表达的事）；不管场景循环。
**待定**：无（远景无预算——R39 全岛 8 棵上限天然封顶，多岛时代的预算问题已随单岛化失效）。
