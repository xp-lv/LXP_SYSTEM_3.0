# 06.2 · 星球导航 · 全定义

> 父模块：[星球](./06-星球模块.md) · 状态：〔已定义〕

**是什么**：星系内的层级浏览与进出（只读导航）。

**行为**
- 两个入口：**右键树**（W6）、**点任务大纲条目**（W9：非叶行=该节点；叶行=其父节点）；
- 单击行星=下钻该子级星系（相机跟随取景）；
- 单击中心球=返回上一级星系；在顶层再返=退出；
- 右键/Esc=随时退出回树；
- 悬停=球体高亮+连线点亮（P5）。

**输入 → 输出**
- 读：当前星球焦点（T4 第三级）；写：焦点迁移（导航事件，不改数据）。

**承接**：W6/W9/P2/P3/P4/P5 · T4 · R40（无编辑）。

**验收**
- 下钻/返回/退出三层导航全部可达，不进叶子死胡同〔手〕。

**边界**：不写数据；不下钻到叶子（叶子无星系）。
**待定**：退出后的相机落点（回到进入前视角 or 树全景）。
