# 05.5 · 进度读数 · 全定义

> 父模块：[今日](./05-今日模块.md) · 状态：〔已定义〕

**是什么**：今日的负载与完成度读数（顶带）。

**行为**
- 顶带三件：日期 · **负载 X/Yh**（X=当日已排工时，含临时/补点/已完成——与 R24 波浪水位同口径，度量排期密度而非剩余量；Y=日容量）· **总进度环**；
- 负载文字旁带 **mini 水位条**（~64px 宽）：与泡泡 wave 同色系三态——
  <80% 绿 / ≥80% 琥珀 / ≥100% 红（超容提醒不阻止，R24 同源）；
- 总进度环=今日整体完成度，**工时加权**——计入临时任务与补点任务
  （今日实际负担，1h 与 8h 不等权）；
- 随勾选即时更新；日视角下按查看日计算。

**输入 → 输出**
- 读：当日清单（工时/完成态）、caps；纯读，无写。

**承接**：T8 顶带部分 · R23/R25（容量与补点计入口径）。

**验收**
- 环=Σ(已完成工时)/Σ(当日工时)，含 temp/makeup〔自〕；
- 负载 X/Y 与泡泡水位同源同值〔自〕；
- 水位条三态色与泡泡 ok/warn/over 一致，超容变红不阻止操作〔手/视〕。

**边界**：不做树/世界读数（顶栏读数在信息模块）。
**待定**：无。
