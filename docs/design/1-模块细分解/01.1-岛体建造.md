# 01.1 · 岛体建造 · 全定义

> 父模块：[岛屿](./01-岛屿模块.md) · 状态：〔已定义·demo 验证〕（v2：增领域扇区着色）

**是什么**：生成并维护那座承载所有树的浮空岛（地形、悬崖、植被、树位、领域扇区色差）。

**行为**
- 生成岛体：草甸地形（树位=隆起的峰）、层理岩悬崖裙边、钟乳石底、草丛/花/晶簇等地表植被；
- 岛随树数生长/收缩；0 树=空岛初始态；
- 为每棵树提供落脚落位与地面高度（树基的来源）；
- **领域扇区着色**（01.3）：草甸网格按树坑位所在领域扇区着色——同领域色相一致，分界渐变过渡（无硬边界）；空领域扇区=浅灰草甸。

**输入 → 输出**
- 读：树坑表（位置/峰高/占用/领域）、领域表；
- 提供：岛网格、任意点的地面高度、树的世界落位。

**承接**：T3/T8（生长/重建时机）· R37（活树位置不动）· 01.3（扇区规则）· 验收 C1。

**验收**
- 删树后其余树位置逐帧不变〔自〕；种 N 树→岛幅单调不减〔自〕；0 树→空岛〔自〕；
- 同领域树的草甸色相一致，不同领域之间有渐变色差〔视〕。

**边界**：不渲染树；不管坑位分配（世界管理）；不直接读领域表（色相由坑位的 domainId 间接驱动）。
**待定**：无（视觉参数以 demo 实现为准）。
