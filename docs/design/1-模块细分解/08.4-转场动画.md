# 08.4 · 转场动画 · 全定义

> 父模块：[交互](./08-交互模块.md) · 状态：〔已定义·旧实现收编〕

**是什么**：页面切换的视觉连续层（共享元素飞移）。

**行为**
- **月↔周**：月详情周度球 → 周规划周度条（分散飞移/收拢飞回）；
- **周↔日**：七日泡泡 → 今日底部日条（同构飞移）；
- 原理：起飞前强制完成落位框的入场动画→克隆飞移元素→真身就位后移除克隆
  （杜绝克隆与真身错位）；
- 只动视觉：页面状态切换由视图路由完成，本模块不做状态；
- 时长入统一节奏表（4 号欠账 #4）。

**输入 → 输出**
- 读：切换事件+两端元素位置；驱动克隆动画。

**承接**：K7（月↔周）、T6/T7（周↔日）· T15 · T17 协作（起飞前 finish）。

**验收**
- 往返切换无错位、无残影〔手/视〕；快速连切不产生动画堆积〔手〕。

**边界**：不做页面内容渲染；不处理数据。
**待定**：无（参数收编旧实现）。
