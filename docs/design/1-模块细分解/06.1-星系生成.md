# 06.1 · 星系生成 · 全定义

> 父模块：[星球](./06-星球模块.md) · 状态：〔部分待设计〕

**是什么**：把一棵树或一个节点呈现为星系（树的另一种呈现）。

**行为**
- 目标（树根或任意节点）→中心球；直接子级→行星（绕心公转）；孙级→卫星（绕行星）；
- 更深层折叠进卫星——孙级卫星若有子节点，标签旁显示**计数角标**（如 ×3）；点击该卫星下钻（P2），以该孙级为根展开新星系。〔已定〕
- 球体携带目标语义着色：与新三态对齐（待排期/已排期/完成——按"时间维度"拍板定档）；
- 只读：数据不变，纯粹换一种呈现。

**输入 → 输出**
- 读：目标子树结构+派生（进度/断梢/排期状态）；提供：星系场景与拾取注册。

**承接**：P1/P2 · T4（星球焦点）· 验收 C6。

**验收**
- 进入正确目标的星系（中心=目标，行星=子级）〔手〕。

**边界**：不提供编辑；叶子节点不生成星系（无子级可展）。
**已定**：D1=不上树 → 球体语义沿用 agg 四键映射 PALETTE（done=金/overdue=红/assigned=绿/floating=红光色）。深层折叠=计数角标+下钻。
