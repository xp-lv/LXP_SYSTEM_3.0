# 月度详情「周度云朵」方案调研

调研日期：2026-10-25  
新增约束：不要表格、不要方框、不要横向周列；周度要灵动；可以在月度详情上部放气泡/云朵；鼠标悬停高亮本周任务。

---

## 1. 为什么放弃右侧纵向周尺

- 纵向周尺虽然打破了“三条横带”，但它仍然是“行 + 竖线 + 标签”的列表结构。
- 视觉上像表格/目录，太规整、太死板。
- 它占用了树画布的宽度，1280 下树被裁切。
- 用户要的是“灵动”，不是“更整齐”。

---

## 2. 新方向：周度云团（Week Cloud Cluster）

把周度从“列表/列/尺”变成一组漂浮在月度详情上部的**有机云团**：

```
┌ 月度详情 ──────────────────────────────────────────────┐
│   ☁ 第1周        ☁ 第2周          ☁ 第3周 本周    ☁ 第4周 │
│   10/4–10/10     10/11–10/17       10/18–10/24     10/25–10/31│
│   0项            6项·20h           6项·16h          0项       │
│                                                             │
│        10月 ── 完成采购表 ── 定制材料的模型构建             │
│              └─ 构建完整的三维模型 ── ...                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

- 云团在详情上部，像一片“周度天空”，不占底部、不占右侧。
- 没有卡片、没有边框、没有表格线；只有有机形状、文字、色点。
- 树画布回到全宽，不再被周尺挤压。

---

## 3. 形态设计

### 3.1 云团形状

不要画卡通的三个圆云朵，而是做“雾团/鹅卵石”式的有机形状：

- 不规则 `border-radius`，例如 `58% 42% 55% 45% / 45% 55% 45% 55%`；
- 每个云团形状略有差异，避免复制感；
- 低饱和平涂或极轻渐变；
- 不用 1px 实线边框；用柔和的同色系边缘/内发光区分层次；
- 阴影很轻，像浮在画布上方，不是卡片投影。

视觉关键词：**雾团、鹅卵石、浮岛、云影**，不是“卡通云”。

### 3.2 大小与布局

- 4–6 个云团，沿一条轻微弧线/波浪排布，不是等距网格。
- 云团大小跟该周任务量相关：任务多略大，空周略小。
- 垂直位置错落 4–12px，形成漂浮感。
- 当前周云团略大、accent 填充、带“本周”小字。
- 过去周云团透明度降低；未来周云团更轻。
- 空周云团只显示很淡的 `＋` 或“空”，不画虚线框。

### 3.3 内容

每个云团内部只放三行：

1. `第N周`（11–12px/600）
2. `10/4–10/10`（8.5–9px）
3. `0项` 或 `6项 · 20h`（8.5–9px）

任务不常驻显示，避免云团变成卡片；鼠标悬停时用树上的高亮来表达任务，而不是在云团里堆任务名。

---

## 4. 核心交互：悬停高亮本周任务

这是这个方案最重要的部分。

- 鼠标移入某个周云团：
  - 云团轻微放大（1.03–1.05），亮度提升；
  - 其他云团降到 0.55 透明度；
  - 树画布中所有属于该周的任务卡片高亮：accent 描边 + 轻微外发光；
  - 非本周任务降到 0.45 透明度；
  - 祖先节点保留正常透明度，但连线变淡，避免整棵树消失。
- 鼠标移出：
  - 云团恢复；
  - 树节点恢复；
  - 过渡 140–180ms，不要弹跳。
- 当前周云团可以有一个非常慢的呼吸/漂浮动画（6–8s），减少动态偏好下关闭。

这样用户不需要在云团里读任务名，而是“云团指周，树上看任务”，空间关系非常直接。

---

## 5. 其他交互

1. **点击云团**：进入周规划；云团形变为周度条胶囊，保留飞移动画。
2. **拖任务到云团**：云团放大、边缘变 accent、显示 `→ 第2周` 幽灵标签；松手写 `assignW`。
3. **空周云团**：悬停时才出现 `＋ 拖入`，不画框。
4. **当前周**：云团 accent 填充 + “本周”文字；不额外加边框。
5. **多周任务重叠**：悬停只高亮该周任务；其他周任务变淡，但不隐藏。

---

## 6. 为什么它比周尺/周列灵动

- 没有行、列、分隔线、边框，结构上不是表格。
- 云团大小、位置、形状都有轻微差异，有“漂浮”感。
- 信息密度低，但通过树高亮补足任务信息。
- 占据详情上部空白，不挤压树画布。
- 和月份列、目标树形成“云 + 树 + 列”的层次，而不是三条横带。

---

## 7. 响应式

- 1600 宽详情：4–6 个云团沿弧线排布，高度约 90–110px。
- 1280 宽详情：云团缩小，允许两行错落；不横向滚动。
- 1024 单列：云团全宽展开，间距更大。
- 2560 宽：云团尺寸略放大，但保持错落，不拉成等距网格。
- 云团高度不占满；下方树画布仍占主要空间。
- 树画布顶部预留 `padTop` 约 100–120px，避免云团压住节点。

---

## 8. 视觉细节

- 云团填充：`--bd-surface-2` 到 `--bd-surface` 的极轻渐变，或 accent 低透明度。
- 当前周：accent 8–10% 填充 + accent 文字；不使用实线边框。
- 阴影：`0 10px 28px rgba(0,0,0,.22)`，比卡片更散。
- 文字：近白/次白；日期用 tertiary。
- 色点：如果显示任务数，可以用 3–5 个小色点表示任务归属；但不要超过 5 个。
- 云团边缘可以有一层非常淡的同色内发光，避免像纯色块。

---

## 9. 落地建议

### P0

- 月度详情上部增加 `.mv-weekclouds` 云团层，高度约 100px。
- 4–6 个有机云团，错落排布；显示周标签、日期、任务数/工时。
- 当前周 accent，过去周降透明，空周淡 `＋`。
- 悬停云团：高亮该周任务、淡化其他任务。
- 点击云团进周规划；拖任务入云团排周。
- 树画布增加 `padTop`，避免云团遮挡。
- 移除右侧纵向周尺。

### P1

- 云团缓慢漂浮/呼吸动画（reduced-motion 关闭）。
- 云团大小按任务量变化。
- 空周悬停展开 `＋ 拖入`。
- 云团点击形变为周度条胶囊。

### P2

- 云团之间用极淡的连线/轨迹连接，形成“周流”。
- 悬停时从云团到高亮任务出现一条很淡的引导线。
- 周/月尺度切换。

---

## 10. 验证重点

- 1600×1000：云团错落、不重叠，树画布全宽。
- 1280×720：云团可两行，树不被挤压。
- 2560×1300：云团不拉成等距网格，仍有漂浮感。
- 悬停：本周任务高亮、其他任务淡化、云团放大。
- 拖任务入云团：云团高亮、幽灵标签、松手排周。
- 点击云团：周规划打开，飞移动画不跳。
- 全程没有表格、列、卡片边框。
