# 月度分配区域调研与重设计方向

调研日期：2026-10-25  
调研对象：飞书多维表格的看板 / 日历 / 甘特视图、飞书任务分组表、飞书画板的分栏与浮层语言  
目标：让「月度分配」区域具备飞书式高级感，并与目标画布、月度详情画布形成同一套画板语言

---

## 1. 这个区域到底要做什么

月度分配不是一张独立的报表，它是目标树和月度详情之间的“时间入口”。核心功能只有五件事：

1. **看见未来 7 个月**：本月 + 后续 6 个月，保持时间连续。
2. **把任务放进月份**：从目标画布拖叶子到某个月，完成月分配。
3. **看见每个月有多满**：任务数、工时、是否超载。
4. **点进某个月**：右侧详情切换到该月的月度任务树。
5. **保持和画布一致**：同一套底色、细边、浮层、拖拽反馈和字号体系。

因此，它不应该再是“七张独立小卡片”，而应该是一个**连续的时间画布**。

---

## 2. 飞书里可借鉴的四种形式

### 2.1 看板视图（Kanban）

飞书多维表格的看板视图是“按字段分组”的列：每列一个状态/负责人/月份，列头有数量和操作，卡片在列内堆叠。

- 优点：拖拽直觉最强；列就是投放区；适合任务分配。
- 缺点：列是“分类”，不是“时间轴”；月份之间没有连续的时间感；列多时仍然是横向卡片墙。
- 适配度：高，但不够“时间”。

### 2.2 日历视图（Calendar）

飞书日历的月视图是标准日期网格，事件以条块落在日期格内。

- 优点：时间感最强；适合日级排期。
- 缺点：月度分配只需要“月”粒度，月网格会浪费大量空白；与周/日视图职责重叠。
- 适配度：低。这个区域不需要 30 个日期格。

### 2.3 甘特 / 时间线视图（Gantt / Timeline）

飞书多维表格的甘特图是左侧任务表 + 右侧连续时间轴；顶部有“周 / 月 / 季 / 年”切换和“今天”定位；任务以彩色圆角条落在时间轴上。

- 优点：连续时间轴；一眼看出任务落在哪个月；时间刻度、今天标记、分段控件都很成熟；视觉高级。
- 缺点：需要开始/结束时间；我们目前只有“分配到某月”，没有精确起止日期。
- 适配度：最高。可以降级为“月份时间线”：每个月一列，任务以短条/芯片落在列内，不要求起止日。

### 2.4 飞书任务分组表

飞书任务表按“进展/负责人”分组，组头有折叠、数量、状态色；顶部是视图页签和轻量工具栏。

- 优点：信息密度高；分组头清晰；状态色克制。
- 缺点：表格形态与思维导图画布不兼容；拖拽分配不如列直观。
- 适配度：中。可以借鉴它的组头、计数、状态标签，但不建议作为主形态。

### 2.5 飞书画板 / 白板分栏

飞书画板本身是无限画布 + 浮动工具条 + 扁平色块；它没有“卡片列表”的概念，所有内容都直接落在画布上。

- 优点：和现有目标画布、月度详情完全同源；没有“框中框”。
- 缺点：如果直接把 7 个月做成画板分栏，容易和主画布的树争夺空间。
- 适配度：高，适合作为“视觉语言”，不适合作为“交互容器”。

## 3. 形式对比

| 形式 | 时间连续感 | 拖拽分配 | 信息密度 | 与画布兼容 | 高级感 | 结论 |
|---|---|---|---|---|---|---|
| 当前独立月卡 | 中 | 强 | 低 | 中 | 低 | 需要替换 |
| 看板列 | 低 | 最强 | 中 | 中 | 中 | 可作为备选 |
| 日历月网格 | 最强 | 中 | 低 | 低 | 中 | 不适合月粒度 |
| 甘特/时间线 | 最强 | 强 | 高 | 高 | 高 | **推荐主形态** |
| 分组表 | 低 | 弱 | 最高 | 低 | 中 | 不适合主区域 |
| 画板分栏 | 中 | 强 | 中 | 最强 | 高 | 作为视觉语言 |

**推荐：以飞书甘特图为骨架，做一条“月份时间线”。**  
不是完整甘特图，而是“7 个月列 + 连续时间轴 + 任务芯片”的轻量版本。

---

## 4. 推荐方案：月份时间线（Month Timeline）

### 4.1 整体结构

```
月度分配                                      [今天]  [时间线 | 卡片]
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ 10月 本月 │ 11月     │ 12月     │ 1月      │ 2月      │ 3月      │ 4月      │
│ 3项 · 22h│ 1项 · 2h │ —        │ —        │ —        │ —        │ —        │
│ ▍写作    │ ▍拆除... │  拖入    │  拖入    │  拖入    │  拖入    │  拖入    │
│ ▍...     │          │          │          │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘
```

- 一条连续的画板带，不是七张独立卡片。
- 每个月是一列，列与列之间只有 1px 细线，没有卡片边框。
- 列头：月份、当前月徽章、任务数/工时、2px 负载条。
- 列身：任务芯片（分支色圆点 + 任务名），最多 3 条 + `+N`。
- 空月份：只显示一条虚线投放提示或一个轻量 `＋`，不再铺满整张卡。
- 选中月份：列底 2px accent 线 + 5% accent 底色；当前月用绿色小徽章区分。

### 4.2 与画布的兼容

- 和「目标画布」「月度详情」共用 `--bd-canvas` / `--bd-line` / `--bd-surface`。
- 没有外层卡片框；标题“月度分配”像其他画板标签一样浮在上方。
- 任务芯片沿用节点语言：10px 圆角、1px 边、分支色小圆点。
- 拖拽反馈沿用画布：accent 插入线 / 列高亮 / 半透明芯片 / 禁止提示。
- 右侧详情被选中时，时间线对应列同步高亮，形成“时间线 → 详情”的空间关系。

### 4.3 交互

1. **点击列**：选中该月，右侧详情切换。
2. **从目标画布拖叶子到列**：整列是投放区；列头出现 `→ 10月` 幽灵标签；松手分配。
3. **点击任务芯片**：选中该月并定位到对应任务。
4. **拖任务芯片到另一列**（建议 P1）：直接改月份，不经过目标画布。
5. **今天**：滚动/高亮当前月；如果当前月不在窗口内，按钮切回。
6. **视图切换**（可选）：`时间线 / 卡片`，给习惯卡片的人保留旧形态；默认时间线。

### 4.4 尺寸与响应式

- 高度：`clamp(132px, 18vh, 180px)`，比现在的 208px 更紧凑。
- 列宽：`grid-auto-columns: minmax(96px, 1fr)`；宽屏自动填满，窄屏横向滚动。
- 列内任务芯片：高 24–28px，字号 10.5px；列头月份 12px/600，meta 9.5px。
- 7 列在 1260px 宽时约 170px/列；在 1280px 页面（左栏约 620px）时约 88px/列，自动横向滚动。
- 低于 1180px 时，月度时间线随规划页单列布局全宽展示。

### 4.5 空态

- 单月为空：列内显示一条 1px 虚线 + “拖入”小字，不画大虚线框。
- 全部为空：在时间线下方显示一行“从目标画布拖一个叶子到月份开始分配”，不占据整个区域。
- 详情为空：右侧沿用现有空态，但 7 个月概览改成迷你时间线缩略图，与主时间线同构。

---

## 5. 为什么不是其他方案

- **继续用七张卡片**：列宽固定、空白多、视觉上像七个独立组件，和画布不连续。
- **看板列**：拖拽好，但月份是时间，不是状态；看板会削弱“未来 7 个月”的时间感。
- **日历月网格**：月粒度不需要 30 个格子，会把空白放大；周/日视图已经有更细的时间表达。
- **完整甘特图**：需要起止日期，当前数据只有 `assignM`；强行加起止日会引入新的输入负担。
- **表格**：信息密度高，但与思维导图画布割裂，拖拽分配也不直观。

---

## 6. 落地建议

### P0

- 把 `#plMonthTrack` 从固定 92px 卡片改成“月份时间线”列布局。
- 列宽 `minmax(96px, 1fr)`，列高 `clamp(132px, 18vh, 180px)`。
- 去掉每张卡的独立边框/背景，改为连续列 + 1px 分隔线。
- 列头：月份 + 当前月徽章 + 任务数/工时 + 2px 负载条。
- 列身：任务芯片，最多 3 条 + `+N`；空列只留虚线投放提示。
- 保留现有拖拽分配、点击选中、右侧详情联动。

### P1

- 任务芯片支持跨列拖动改月份。
- 增加“今天”按钮和当前月自动定位。
- 右侧详情空态的 7 个月概览改成迷你时间线。
- 可选“时间线 / 卡片”视图切换。

### P2

- 季度视图（3 列）或“月 / 季”切换。
- 列内任务超过 3 条时的展开浮层。
- 任务芯片悬停预览工时、周分配和状态。

---

## 7. 验证重点

- 2560×1300：7 列填满左栏，不再在右侧留大块空白。
- 1920×1080、1600×1000：列宽舒适，任务芯片可读。
- 1280×720：列最小 96px，可横向滚动，不挤压文字。
- 1024×768：规划页单列，时间线全宽。
- 任务数量增加时，列宽和字号不变，只增加列内滚动/`+N`。
- 从目标画布拖入月份、点击列进详情、选中态联动都保持正常。
