# 0 · 模块分解（高层）

新系统 = **11 个功能模块**：

| # | 模块 | 一句话定义 |
|---|---|---|
| 1 | **岛屿模块** | 一座承载所有树的浮空岛：地形与树位，随树数生长；领域仅作数据分组，不成岛 |
| 2 | **树模块** | 目标树的呈现：骨架=分解结构，红光=待排期，指线=已排期，叶团=完成 |
| 3 | **顶层目标分解模块** | 主目标→二级→三级的分解与落月（宏观规划） |
| 4 | **周度目标分解模块** | 月度任务→周任务的分解与落日（微观规划） |
| 5 | **今日模块** | 当日执行：事项清单、勾选完成、超时补点 |
| 6 | **星球模块** | 子树的星系化下钻导航：中心球=枝，行星=子任务，卫星=孙任务 |
| 7 | **数据模块** | 任务树的数据模型、汇总派生、存档 |
| 8 | **交互模块** | 相机漫游、点选拾取、视图导航 |
| 9 | **信息模块** | 面板与读数：树选择框、任务大纲、进度 HUD |
| 10 | **环境模块** | 昼/昏/夜时段、天光、氛围粒子 |
| 11 | **AI 规划模块** | 从顶层目标出发，经对话澄清与系统化分解，生成递进文档链；用户确认后经变更服务把方案落成任务树、排期与完成态 |

> **11 号模块的定位**：它是唯一会“提出方案”的模块，但不直接写任务数据——
> 所有落库都经 7 号数据模块的变更服务；AI 的文档、对话、运行记录存服务端受管目录，
> 不进入任务存档。它把“靠直觉分解”升级为“先澄清、再系统拆、看文档、确认后落库”。
