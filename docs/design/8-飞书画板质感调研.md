# 飞书画板流程图质感调研

调研日期：2026-10-24  
调研对象：飞书画板 / Lark Board 的流程图、思维导图、连接线、选择态与浮动工具条  
目的：为「宏观规划」页面提炼可落地的视觉语言，不改变现有业务逻辑与交互模型

---

## 1. 结论先行

飞书画板流程图的“质感”不是靠材质、渐变或阴影堆出来的，而是靠一套非常克制的**图纸语言**：

1. **平涂色块 + 细描边**：节点是扁平的，靠 1–2px 深色轮廓建立边界，不靠投影。
2. **低饱和分区色**：蓝、紫、米黄、浅绿只用于“分类”，大面积仍是纸白或深灰底。
3. **细连接线 + 开放箭头**：线宽约 1.5px，箭头是细线折角，不是实心三角；线本身不抢节点。
4. **8px 网格与大量留白**：节点间距、内边距、工具条间距都落在 8 的倍数附近。
5. **字重建层级，字号很克制**：标题 13–15px/600，正文 12–13px/500，辅助 10–11px；层级主要靠颜色和字重。
6. **浮动 UI 很轻**：工具条、右键菜单、选择框都是白底/深底 + 1px 边 + 柔和大阴影，出现时不压迫画布。

一句话概括：**工程图纸的秩序感 + 便签纸的轻盈感**。它看起来“高级”，是因为没有多余装饰，而不是因为装饰很多。

## 2. 样本与观察

> 以下色值为截图取样近似值，受压缩影响，不作为官方规范。

### 2.1 飞书画板「连接线样式」面板

样本：飞书画板官方功能示意图（直线 / 折线 / 曲线连接线）

- 画布是**暖白/浅灰**，不是纯白，接近 `#F7F7F5`。
- 节点：
  - 圆角矩形，圆角约 8–10px；
  - 填充是低饱和的冰蓝 `#E8EEF7`、米黄 `#FAF0D7`、浅紫 `#E4DDF8`；
  - 描边是近黑深灰，约 1.5px，粗细一致；
  - 无渐变、无投影。
- 连接线：
  - 直线、折线、曲线三种；
  - 线宽约 1.5px，颜色近黑；
  - 箭头是**开放 V 形**，不是实心三角；
  - 折线是直角转弯，曲线是平滑贝塞尔；
  - 连接线标签（“直线连接线”等）直接排在空白处，字号约 15–16px。
- 左侧工具栏：
  - 白色竖条，图标为细线风格；
  - 当前工具用浅灰圆角方块表示，不用蓝色高亮；
  - 二级面板是白色圆角浮层，圆角约 14–16px，带柔和阴影。

### 2.2 飞书画板「选择态 + 右键菜单」

样本：飞书白板选中矩形后的上下文菜单

- 选择框：蓝色（接近 `#3370FF`）约 1.5–2px，内部叠加很淡的蓝色填充。
- 八个控制点是**白色小方块 + 蓝色描边**，旋转手柄是细线圆弧。
- 浮动工具条：
  - 白色、圆角约 10–12px、1px 浅灰边；
  - 按钮之间用 1px 细分隔线；
  - 下拉用一个小 chevron，不额外加边框；
  - 阴影很柔，几乎只用来“托起”浮层。
- 右键菜单：
  - 白底、圆角约 10px、1px 边；
  - 快捷键是浅灰色，右对齐；
  - 菜单项高度约 40px，留白充足；
  - 悬停是浅灰底，不是蓝色底。

### 2.3 飞书思维导图

样本：飞书画板思维导图节点与连接线

- 画布浅灰，节点是**白底 + 2px 紫色描边**，文字近黑。
- 连接线是紫色平滑曲线，无箭头；方向由“从左到右”的布局本身表达。
- 连接线上有圆形 `+` 按钮，用于在中间插入节点；按钮是蓝色圆形 + 白色加号。
- 选中节点时出现浮动工具条：形状、填充、描边、字号、文字颜色、评论、更多。
- 工具条高度约 48px，分组之间有细竖线；图标统一为 1.5px 线宽。
- 关键点：**节点和线是同一套紫色语义**，但节点用描边、线用细线，不互相抢。

### 2.4 Lark 流程图模板

样本：Lark 登录/注册流程图模板

- 形状语义非常清楚：
  - 开始/结束：胶囊形；
  - 处理：矩形；
  - 判断：菱形。
- 填充是深色平涂（藏蓝、砖红、芥末黄），无描边；文字白色、居中、两行以内。
- 连接线是细灰线，正交折线，开放箭头；`Yes/No` 标签放在线旁，不压线。
- 整体没有阴影、没有渐变、没有装饰图标。
- 这套模板证明：**即使颜色较深，只要形状和线足够克制，仍然显得干净。**

### 2.5 Lark 系统架构图模板

样本：Lark 系统架构图模板

- 外层分组容器：
  - 大圆角约 10–12px；
  - 极浅的马卡龙底色（蓝、橙、紫、绿）；
  - 1px 同色系稍深描边；
  - 容器标题在顶部居中，字号小于内部节点。
- 内部节点：
  - 白底、1px 浅色边、圆角约 6–8px；
  - 文字是深灰，字号约 10–11px；
  - 没有投影。
- 层级靠“容器色 + 内层白卡”建立，而不是靠阴影和粗细。
- 这套结构非常适合“目标 → 路径 → 任务”的三层分解。

## 3. 视觉语法拆解

### 3.1 画布（Canvas）

| 项目 | 浅色飞书画板 | 深色适配建议 |
|---|---|---|
| 底色 | 暖白 `#F7F7F5` | 石墨蓝黑 `#0F1218` |
| 点阵 | 很淡，约 3–4% 黑 | `rgba(255,255,255,.035)`，24px 间距 |
| 内容边距 | 24–32px | 20–28px |
| 画布边界 | 不额外描边 | 1px `rgba(255,255,255,.06)` 内描边 |
| 氛围 | 纸面 | 深色图纸，不用纯黑 |

深色模式不要用 `#000`。纯黑会让细线消失、色块发脏；石墨蓝黑能保留“纸”的感觉。

### 3.2 节点（Node）

- **形状**：圆角矩形 8–10px；分组容器 12px；开始/结束可用胶囊；判断用菱形。
- **填充**：平涂。不要 `linear-gradient`，不要内高光。
- **描边**：1–1.5px。浅色模式用近黑；深色模式用 `rgba(255,255,255,.14–.22)` 或同色系 30% 透明描边。
- **内边距**：横向 16–22px，纵向 10–14px；紧凑模式可降到 10–12px / 7–9px。
- **文字**：
  - 标题 13–15px，字重 600；
  - 辅助信息 10–11px，字重 500；
  - 行高 1.35–1.5；
  - 中文不要用 9px 以下做信息文字。
- **层级**：
  - 根节点：更大、更强描边或唯一实色；
  - 二级：分支色浅底 + 同色描边；
  - 三级：中性底 + 中性边，只保留一个小色点。
- **阴影**：默认没有。悬停最多 `0 2px 8px rgba(0,0,0,.18)`；拖拽时才可以有浮起阴影。

### 3.3 连接线（Connector）

- **线宽**：1.5px 常态，2px 激活。
- **颜色**：
  - 中性：`rgba(255,255,255,.28–.38)`（深色）；
  - 分支色：分支色 40–50% 透明；
  - 激活：分支色 90% 或全局 accent。
- **箭头**：开放 V 形，长度 6–8px，线宽与主线一致；不要实心三角。
- **路由**：
  - 流程图优先正交折线，转弯圆角 6–8px；
  - 树状分解可用平滑三次贝塞尔；
  - 线从节点边缘的锚点出发，锚点可以是 3–4px 小圆点。
- **标签**：10–11px，放在线上方或线旁，用画布底色做 2px halo，避免压字。
- **交互**：悬停整条路径高亮；选中节点时，相关路径同步高亮；连接线中点可放 `+` 用于插入节点。

### 3.4 色彩（Color）

飞书画板的色彩比例大致是：

- 90% 中性：纸白 / 石墨 / 深灰文字；
- 8% 分类色：蓝、紫、米黄、浅绿，低饱和；
- 2% 交互色：蓝色选择框、紫色连接线、状态点。

深色适配建议：

| Token | 建议值 | 用途 |
|---|---|---|
| `--bd-canvas` | `#0F1218` | 画布底 |
| `--bd-surface` | `#151922` | 节点/卡片底 |
| `--bd-surface-2` | `#1A1F2A` | 浮层/嵌套块 |
| `--bd-line` | `rgba(255,255,255,.10)` | 常规边 |
| `--bd-line-strong` | `rgba(255,255,255,.18)` | 悬停/选中边 |
| `--bd-text` | `#E9ECF4` | 主文字 |
| `--bd-text-2` | `#A7AEC0` | 次文字 |
| `--bd-text-3` | `#6E7689` | 辅助文字 |
| `--bd-accent` | `#8B96F8` | 交互/选择 |
| `--bd-blue-fill` | `rgba(91,155,230,.14)` | 蓝分类底 |
| `--bd-lav-fill` | `rgba(139,150,248,.14)` | 紫分类底 |
| `--bd-cream-fill` | `rgba(217,161,62,.12)` | 米黄分类底 |
| `--bd-green-fill` | `rgba(76,195,138,.12)` | 绿分类底 |
| `--bd-rose-fill` | `rgba(229,105,111,.12)` | 红分类底 |

圆角建议：节点 10px，容器 12px，胶囊 999px。  
描边建议：节点 1px，选中 2px，容器 1px。  
阴影建议：只有浮层用 `0 12px 32px rgba(0,0,0,.45)`；节点默认无阴影。

### 3.5 工具条与选择态（Toolbar & Selection）

- 浮动工具条：`--bd-surface-2` + 1px 边 + 12px 圆角 + 柔和大阴影。
- 分段控件：高度 28–32px，按钮之间 1px 分隔线，选中项用浅色底，不用高饱和蓝。
- 选择态：2px accent 描边 + 3px 外扩淡色环；控制点是深底小方块 + accent 边。
- 焦点态：必须保留 `:focus-visible` 环，不能只靠 hover。
- 动效：120–160ms；悬停位移不超过 1px；不要缩放超过 1.02。

### 3.6 留白与网格

- 基础间距 8px；常用 8 / 12 / 16 / 24。
- 同级节点水平间距 ≥ 32px，垂直间距 ≥ 16px。
- 分支之间至少留 24px，避免连线交叉。
- 画布内容不要贴边，四周至少 24px。

## 4. 与当前宏观规划页的映射

### 4.1 目标画布

当前：深色凹陷井 + 紫色点阵 + 渐变卡片 + 低透明度发光线。  
建议：

- 画布改为 `--bd-canvas` 平色，点阵降到 3.5%；
- 节点改为平涂 + 1px 边，按顶层分支着色（蓝/绿/金/红/青/粉）；
- 根节点用胶囊或更强描边，明确“起点”；
- 连接线加开放箭头，分支色 40%，激活 90%；
- 在画布左侧加一条很淡的“目标 → 路径 → 任务”列引导，不需要文字很大；
- 选中节点时显示 8 个控制点或至少 2px accent 环。

### 4.2 月度卡片

当前：92px 宽，渐变底，发光选中环，顶部 3 条任务。  
建议：

- 改成“便签列”：平涂底 + 1px 边 + 顶部 3px 分支色条；
- 当前月用 accent 1px 边 + 小 `NOW` 胶囊，不用外发光；
- 卡片内最多 2 条任务 + `+N`，把密度降下来；
- 负载条改成 2px 细线，超载才变红；
- 悬停只抬升 1px，不加多层阴影。

### 4.3 月度详情

当前：与目标画布同一套深色卡片，KPI 胶囊，底部周泡泡。  
建议：

- 画布语言与目标画布完全一致，避免“两个产品”；
- KPI 胶囊改成扁平小标签，数字用 600 字重；
- 周泡泡用 1px 边 + 浅色底，拖入时用 dashed accent，不用绿色 glow；
- 空状态统一成“虚线画板 + 三个 ghost 节点”。

### 4.4 页头与工具条

当前：标题 + 统计胶囊 + fit/zoom 按钮，比较像控制台。  
建议：

- fit/zoom 收进一个浮动 segmented 工具条，放在画布右下或页头右侧；
- 统计胶囊保留，但改成 1px 边、无底色或极浅底色；
- 深度轨道改成细虚线 + 小圆点，弱化“仪表盘”感。

## 5. 当前页面可改进的 10 个问题

1. **节点层级不够清楚。** 根、二级、三级主要靠字号和边框区分，缩到 92px 月卡附近时几乎一样重。建议根节点用胶囊/实色，二级用分支色浅底，三级回到中性底 + 小色点。
2. **连接线没有方向。** 当前是 1.3px、低透明度、无箭头的贝塞尔线，读者只能靠布局猜方向。建议加 6–8px 开放箭头，常态 1.5px，悬停/选中 2px。
3. **卡片仍有渐变和内高光。** 在深色小尺寸下容易发灰、发脏，和飞书画板的“平涂”质感相反。建议节点默认平涂 + 1px 边，只有浮层保留阴影。
4. **强调色太多。** 紫、绿、金、红、蓝同时出现在边线、徽章、负载条、状态点上，视觉噪音大。建议 90% 中性 + 8% 分支色 + 2% 交互色，状态色只出现在状态点。
5. **字号偏小且层级平。** 9–12px 的信息很多，关键标题不够突出。建议标题 12.5–13px/600，辅助 9.5–10px/500，行高 1.4；不要用 9px 以下承载信息。
6. **月卡太窄、信息过密。** 92px 内同时放月份、工时、负载条、3 条任务、`+N`，读起来拥挤。建议 104–112px，或保持 92px 但只显示 2 条任务 + `+N`，其余进悬停浮层。
7. **目标画布缺少“起点”和方向提示。** 用户不知道根在哪、树往哪长。建议加一个明确的根节点样式、左侧列引导，以及首次进入时 2 秒的轻提示。
8. **自由拖动后容易丢失内容。** 没有 minimap、没有“回到中心”、没有离屏指示；拖远后只能靠 fit。建议加右下角 minimap 或“重置布局”，并在内容超出视口时显示方向箭头。
9. **空状态/边界状态不统一。** 目标画布、月详情、月卡各有一套 dashed/empty 样式。建议统一成一个“画板空态”组件：虚线框 + ghost 节点 + 一行说明 + 一个主按钮。
10. **交互可发现性不足。** `+` 只在 hover 出现，自由拖动没有光标提示，连接线不能插入节点，键盘用户无法完整操作。建议选中/悬停时常驻边缘 `+`，增加 `grab/grabbing` 光标、连接线中点 `+`，并补齐 Tab/Enter 与 focus ring。

## 6. 建议的落地顺序

**P0（决定质感）**

- 建立 board token（画布、节点、线、文字、圆角、阴影）；
- 节点改平涂 + 1px 边；
- 连接线加开放箭头与分支色；
- 根/二级/三级建立明确层级；
- 统一选中态。

**P1（决定可读性）**

- 月卡降密度、当前月样式；
- 统一空状态；
- 页头工具条化；
- 拖动后的空间反馈（minimap / 重置）。

**P2（决定完成度）**

- 连接线中点插入节点；
- 键盘操作与焦点环；
- 首次使用引导；
- 细节动效（120–160ms）。
