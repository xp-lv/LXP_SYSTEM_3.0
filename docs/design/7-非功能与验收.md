# 7 · 非功能与验收

> 系统的**运行边界**（性能/平台/错误）与**每个最小模块的验收口径**。
> 验收分三档：〔自〕自动断言（单测/探针）·〔手〕手动走查 ·〔视〕视觉验收（截图对照）。
> 数字大多为 ⚖️ 骨架值——按实现机型的实测回填。

---

## D · 验收基础设施

- 〔自〕断言全部进单测（`impl/tests/run.mjs`，纯逻辑零 DOM/three）；
- 架构规则可执行化（`impl/tests/check.mjs`）：六机制+死导出+导入图闭合，失败即架构漂移；
- 树/世界类断言经调试探针（横向支撑·调试探针）在浏览器内执行；
- 〔视〕验收以截图对照 demo 参考画面（demo/tree-proj）；
- AI 模块额外进单测/集成测试：工具参数校验、批量落库回滚、文档路径穿越、
  Markdown 清洗、密钥泄露扫描、未确认/stale 拦截、planRun 追溯；
- 每条 ⚖️ 数字回填后，本文档从骨架升级为 v1。
- 回填条件：impl 全功能可跑后一次性实测（建树耗时用 `__demo.world()` 计时；存档体积用 exportJSON 长度；帧率用 rAF 间隔统计 60s），结果直接写入本表。
