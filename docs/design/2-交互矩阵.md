## 关系清单

### A · 数据通道（7 数据为枢纽——一切写经它、一切读自它）

| 模块对 | 交互 |
|---|---|
| 7—1 岛屿 | 领域分组与树归属、世界形态（树数→岛规模）的存取 |
| 7—2 树 | 树读任务结构与状态成树；任务变更 → 树上三态即时更新（红光熄灭/叶团生长） |
| 7—3 顶层 | 分解、落月、移出、换月等写操作；读当前树供编辑 |
| 7—4 周度 | 周分解、工时、落日、临时任务的写操作 |
| 7—5 今日 | 勾选、补点、临时的写操作；读当日清单 |
| 7—6 星球 | 读子树结构生成星系 |
| 7—9 信息 | 读派生结果（进度/断梢/过期/工时）供各读数展示 |

### B · 世界内交互（3D 场景中的拾取与漫游）

| 模块对 | 交互 |
|---|---|
| 1—2 岛屿—树 | 所有树长在同一座岛上：岛给树落位与地面；岛随树数生长 |
| 8—2 交互—树 | 单击树=激活该树（相机聚焦） |
| 8—6 交互—星球 | 右键树=进入该树星系；星系内点行星=下钻、点中心=返回、右键=退出 |
| 8—5 交互—今日 | 点落果=补点、点果=勾选、今日固定机位与自由漫游 |
| 8—9 交互—信息 | 悬停触发详情卡 |
| 9—6 信息—星球 | 点任务大纲条目=进入该节点的星球视图 |

### C · 页面导航链（规划链路上的视图切换）

| 模块对 | 交互 |
|---|---|
| 3—4 顶层—周度 | 月详情点周度球=跳该周；周度条再点当前周=回宏观（飞移动画） |
| 4—5 周度—今日 | 点日泡泡=进当日视角；底部日条再点当前日=回周 |
| 3—1 顶层—岛屿 | 宏观页种植新树 → 树落到岛上生长 |
| 3—2 顶层—树 | 激活的树即宏观编辑的对象（所见即所编） |

### D · 呈现与氛围

| 模块对 | 交互 |
|---|---|
| 10—1 环境—岛屿 | 光照与阴影落在这座岛上；时段改变岛的观感 |
| 10—2 环境—树 | 风摆树摇；夜晚红光成灯、叶团带微光 |
| 2—5 树—今日 | 今日周树复用树模块的形态语言（同一种树） |
| 2—6 树—星球 | 星球是树的另一种呈现（退场/回场切换） |
| 2—9 树—信息 | 悬停卡读树上任务档案；树上状态供大纲/读数展示 |

### E · AI 规划链（11）

| 模块对 | 交互 |
|---|---|
| 11—1 AI—岛屿 | 读领域/树列表；经世界管理创建目标树（受 R39 上限）；落库后树在世界中生长 |
| 11—3 AI—顶层 | 读顶层结构；落库时创建/改名/落月；方案预览按顶层画布口径呈现 |
| 11—4 AI—周度 | 读周/日负载；落库时落周/落日/改工时；容量校验 |
| 11—5 AI—今日 | 读当日执行与完成态；用户确认后可完成指定任务 |
| 11—7 AI—数据 | 一切任务读写经变更服务：读 `queries`、写 `mutations`；落库=批量事务+一步 undo |

> AI 与 2 树 / 6 星球 / 8 交互 / 9 信息 / 10 环境无直接交互：
> 树的呈现、读数、星球与动画都由 7 数据模块的变更传播链间接更新；
> AI 的“AI 规划”全屏页与文档查看器属于模块自带 UI，入口走横向“视图路由”。

## 读法

- **数据模块是唯一枢纽**：7 个模块直接连它，且所有写操作只经它——这是系统的第一条红线；
- **树模块是视觉枢纽**：与其余模块中 8 个有交互，是"世界—规划—今日—星球"共用的呈现语言；
- **交互模块不写数据**：它只把"点到了什么"路由成动作，写永远走数据通道；
- **环境是纯作用者**：只影响岛屿与树的观感，不接收任何业务信息；
- **顶层/周度/今日之间只有导航关系**（C 组），互相不直接读写——
  它们的耦合全部通过数据模块间接完成；
- **AI 是上游规划者**：它读数据、提方案、等用户确认，再经数据模块落库；
  它不绕过 7 号，也不直接驱动树/星球/环境。
