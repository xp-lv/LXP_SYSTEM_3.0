# 交互走查清单（7号 G6）

> 对应《3-交互全定义》50 条交互。手动走查，逐条勾选 `[x]`。

## 1.1 世界（11 条）

- [ ] W1 左键拖拽=相机旋转
- [ ] W2 右键/Shift拖拽=相机平移
- [ ] W3 滚轮=缩放
- [ ] W4 单击树=激活（相机聚焦该树，非全岛）
- [ ] W5 双击=聚焦子树（包围球取景）
- [ ] W6 右键树=进入该树星球
- [ ] W7 悬停=详情卡（工时/排期/状态 chips）
- [ ] W8 树选择框点行=激活该树
- [ ] W9 大纲点行=进入星球（非叶=该节点，叶行=父节点）
- [ ] W10 时段按钮=昼/黄昏/夜
- [ ] W11 顶栏「回正」=回岛全景
